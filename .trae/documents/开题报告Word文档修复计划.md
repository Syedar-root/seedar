# 开题报告 Word 文档修复计划

## 问题描述
1. **标题格式问题**：原 MD 格式的标题（# ## ###）未正确转换为 Word 标题样式
2. **加粗格式问题**：原 MD 格式的加粗（**text**）未正确转换为 Word 加粗

## 问题分析

### 问题 1：标题识别逻辑错误
当前代码第 80-81 行：
```javascript
if (line.startsWith('# ') && !line.includes('学位')) {
    children.push(addHeading(line.replace('# ', ''), HeadingLevel.HEADING_1));
}
```
- 排除了包含"学位"的标题（这是封面标题，不需要作为章节标题）
- 但没有处理多个 `#` 的情况（如 `##` 应该是 H2）

### 问题 2：加粗解析逻辑错误
当前代码第 16 行的正则表达式 `split(/(\*\*|__|\*|_|\`)/)` 会导致：
- `**text**` 被分割成 `['**', 'text', '**']`
- 但后续的 while 循环逻辑不正确，没有正确判断哪些部分是加粗的

## 修复方案

### 步骤 1：重写加粗解析函数
使用正确的正则匹配 `**text**` 格式：
- 使用 `match(/(\*\*|__)(.+?)\1/g)` 匹配加粗内容
- 或使用更简单的方法：逐字符扫描

### 步骤 2：修复标题识别
- 正确识别 `# ` `## ` `### ` 并转换为对应级别
- 移除排除"学位"的逻辑（直接用正则匹配）

### 步骤 3：重新生成文档

## 实施步骤
1. 修改 `scripts/generate-docx.js` 中的解析逻辑
2. 运行脚本重新生成文档
3. 验证标题和加粗是否正确转换
