# 方案2实现计划：DatasetField 作为 expression 的验证目标

## 背景
当前 `dataset.helper.ts` 中，解析 expression 的 `#F` 和 `#M` 后，将字段ID直接放入 `validColIds` 用于查询 `DatasourceColumn`，但 `#F` 引用的是 `DatasetField` ID，不是 `DatasourceColumn` ID。

## 需要修改的文件

**1个文件：** `apps/server/src/module/dataset/services/helper/dataset.helper.ts`

## 修改步骤

### 步骤1：修改验证逻辑结构

**当前逻辑（第259-264行）：**
```typescript
if (metric.expression) {
  const { fieldIds, metricIds } = parseExpressionIds(metric.expression);
  validColIds.push(...fieldIds);  // ❌ 错误：把 DatasetField ID 当 DatasourceColumn ID
  validMetricIds.push(...metricIds);
}
```

**修改为：**
```typescript
if (metric.expression) {
  const { fieldIds, metricIds } = parseExpressionIds(metric.expression);
  // #F 引用的字段ID 记录到 validFieldIds，用于验证 DatasetField
  validFieldIds.push(...fieldIds);
  validMetricIds.push(...metricIds);
}
```

### 步骤2：添加 validFieldIds 变量

**在第227行附近添加：**
```typescript
const validFieldIds: number[] = [];  // 新增：用于验证 DatasetField
```

### 步骤3：修改查询逻辑

**第三步查询逻辑（第287-298行）需要改为：**

1. **查询 DatasetField**（使用 validFieldIds）
2. **查询 DatasourceColumn**（使用原来的 validColIds，如 dataSourceColumnId）

```typescript
// 3.1 查询 DatasetField（用于 expression 中的 #F 引用）
let fieldMap = new Map<number, DatasetField>();
if (validFieldIds.length > 0) {
  const fields = await manager.find(DatasetField, {
    where: { id: In(validFieldIds), dataSetId },
  });
  fieldMap = new Map<number, DatasetField>(fields.map(f => [f.id, f]));
}

// 3.2 查询 DatasourceColumn（用于直接的 dataSourceColumnId 引用）
let columnMap = new Map<number, DatasourceColumn>();
if (validColIds.length > 0) {
  const columns = await manager.find(DatasourceColumn, {
    where: { id: In(validColIds), tableId: In(datasourceTableIds) },
  });
  columnMap = new Map<number, DatasourceColumn>(columns.map(c => [c.id, c]));
}
```

### 步骤4：更新验证逻辑

**在指标创建验证处（第245-264行），改为验证 DatasetField：**

```typescript
// 验证 DatasetField 是否存在
for (const fieldId of validFieldIds) {
  const field = fieldMap.get(fieldId);
  if (!field) {
    warnings.push(`expression 中引用的字段 ${fieldId} 不存在`);
  }
}
```

## 完整修改清单

| 位置 | 修改内容 |
|------|---------|
| 第227行附近 | 添加 `validFieldIds: number[] = []` |
| 第259-264行 | 将 `validColIds.push(...fieldIds)` 改为 `validFieldIds.push(...fieldIds)` |
| 第287-298行 | 新增查询 DatasetField 的逻辑 |
| 第305-320行 | 验证 DatasetField 存在性 |

## 影响范围

- 仅影响 V2 版本的 expression 指标
- V1 版本的指标（使用 dataSourceColumnId）不受影响
- 无需修改数据库结构
