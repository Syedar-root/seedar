# 文档排版调整计划

## 任务概述

以 `d:\projects\seedar\docs\v0\开题报告.docx` 为模板，对 `d:\projects\seedar\docs\v1\开题报告.docx` 进行排版调整。

## 文档现状分析

### V0 模板样式结构
| 样式 | 数量 | 用途 |
|------|------|------|
| Heading 1 | 7 | 章节标题 |
| Heading 2 | 7 | 二级标题 |
| Heading 3 | 17 | 三级标题 |
| Normal | 124 | 正文 |
| List Paragraph | 57 | 列表项 |

### V1 当前样式结构
| 样式 | 数量 | 用途 |
|------|------|------|
| Heading 1 | 4 | 章节标题 |
| Heading 2 | 11 | 二级标题 |
| Heading 3 | 13 | 三级标题 |
| Heading 4 | 15 | 四级标题（模板中不存在） |
| None（无样式） | 164 | 正文/列表（需要修复） |

## 需要调整的问题

1. **164个无样式段落** - V1中大量正文段落未应用样式，需要批量设置为 Normal
2. **Heading 4 不符合模板** - 模板最高只有 Heading 3，需要将 Heading 4 调整为正文或三级标题
3. **列表项样式缺失** - 列表内容未使用 List Paragraph 样式，需要修复
4. **字体格式不统一** - 需要统一为 Times New Roman, 5号字
5. **段落格式不统一** - 需要设置行距1.25倍、段前段后间距、首行缩进等

## 执行步骤

### 步骤1：解压V1文档
```bash
python scripts/office/unpack.py "d:\projects\seedar\docs\v1\开题报告.docx" unpacked_v1/
```

### 步骤2：分析并修改 document.xml

需要修改的内容：

1. **将所有无样式段落设置为 Normal 样式**
   - 查找 `<w:pStyle w:val="None"/>` 或缺少样式的段落
   - 添加 `<w:pStyle w:val="Normal"/>`

2. **将 Heading 4 转换为正文或三级标题**
   - 查找 `<w:pStyle w:val="Heading 4"/>`
   - 替换为 `<w:pStyle w:val="Normal"/>` 或 `<w:pStyle w:val="Heading 3"/>`

3. **统一字体格式**
   - 在 Normal 样式的段落中统一设置中文字体为宋体，英文为 Times New Roman
   - 字号统一为5号（10pt）

4. **设置段落格式**
   - 行距：1.25倍
   - 对齐方式：两端对齐
   - 首行缩进：2字符

### 步骤3：打包生成新文档
```bash
python scripts/office/pack.py unpacked_v1/ "d:\projects\seedar\docs\v1\开题报告_排版后.docx" --original "d:\projects\seedar\docs\v1\开题报告.docx"
```

## 技术方案

根据 docx 技能指南，使用以下方法：

1. 使用 `python-docx` 库直接读取和修改样式
2. 或者使用 unpack → edit XML → pack 的方式修改

由于需要批量修改164个段落的样式，推荐使用 XML 直接修改的方式，效率更高。

## 预期结果

- 所有正文段落应用 Normal 样式
- 移除 Heading 4，全部转换为正文
- 字体、字号、行距等格式统一
- 文档排版与V0模板保持一致
