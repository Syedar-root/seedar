### 步骤 4：创建 `metricEditorDialog.tsx`
**文件路径**: `d:\Program\projects\seedar\apps\web-client\src\modules\panel\components\aside\metricEditorDialog.tsx`

**创建内容**:
完整的指标编辑器对话框组件，包含：

**Props 接口**:
```typescript
interface MetricEditorDialogProps {
  datasetId: number;
  fields: DatasetFieldResponse[];
  metrics: DatasetMetricResponse[];
  onClose: () => void;
  onSuccess: () => void;
}
```

**状态管理**:
- 基础信息：`metricType`, `name`, `businessName`, `description`
- 聚合指标：`dataSourceColumnId`, `aggregateFunction`, `distinct`, `aggregateCondition`
- 行级指标：`leftOperand`, `leftOperandFieldId`, `rowOperator`, `rightOperand`, `rightOperandFieldId`
- 后聚合指标：`sourceMetricId`
- 算术运算指标：`leftMetricId`, `arithmeticOperator`, `rightMetricOperand`, `rightMetricOperandFieldId`

**核心功能**:
1. 使用 `@base-ui/react/dialog` 创建模态框
2. 使用 `useUpdateDataset` hook 调用后端 API
3. 根据指标类型动态显示不同的表单区域
4. 表单验证（必填字段、JSON 格式）
5. 提交时构造符合 `AddMetric` 类型的数据
6. 成功后调用 `onSuccess` 回调

**表单区域**:
- 基础信息区域（所有指标类型通用）
- 聚合配置区域（仅聚合指标）
- 行级运算配置区域（仅行级指标）
- 后聚合配置区域（仅后聚合指标）
- 算术运算配置区域（仅算术运算指标）

**字段过滤**:
- `numericFields`: 过滤出数字类型的字段（用于聚合、行级、算术运算指标）

## 功能清单

### 支持的指标类型
- ✅ 聚合指标（aggregate）
- ✅ 行级指标（row_level）
- ✅ 后聚合指标（post_aggregate）
- ✅ 算术运算指标（arithmetic）

### 表单字段
- ✅ 基础信息：指标类型、名称、业务名称、描述
- ✅ 聚合指标：数据源列、聚合函数、去重、聚合条件 JSON
- ✅ 行级指标：左操作数（字段/数字）、运算符、右操作数（字段/数字）
- ✅ 后聚合指标：源指标
- ✅ 算术运算指标：左指标、运算符、右操作数（指标/字段/数字）

### 数据流
- ✅ 从父组件接收 `datasetId`、`fields`、`metrics`
- ✅ 使用 `useUpdateDataset` hook 调用 `PATCH /dataset` API
- ✅ 成功后触发 `onMetricCreated` 回调
- ✅ 表单验证和错误提示

### 用户体验
- ✅ 模态框打开/关闭
- ✅ 动态表单显示
- ✅ 必填字段标记
- ✅ 加载状态显示
- ✅ 成功/失败提示

## 注意事项

1. **样式简化**: 使用固定的颜色值（如 #3b82f6、#e5e5e5）而非 CSS 变量，保持简洁
2. **表单验证**: 指标名称必填，各类型指标的必填字段验证
3. **JSON 验证**: 聚合条件输入时验证 JSON 格式
4. **字段过滤**: 根据指标类型过滤可用字段（数字字段、日期字段等）
5. **互斥选择**: 字段选择和数字输入互斥，选择字段时清空数字，反之亦然
