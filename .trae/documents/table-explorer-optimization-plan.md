# 「亲和型分层展示」TableExplorer 优化计划

## 背景

- **目标用户**：业务人员为主，技术人员为辅
- **设计风格**：温暖优雅、简约高级
- **核心理念**：业务人员看到"易懂的"，技术人员能快速找到"想要的"

---

## 改造范围

| 文件 | 改造内容 |
|------|---------|
| `TableExplorer.tsx` | 字段行分层结构、交互逻辑 |
| `TableExplorer.module.scss` | 布局调整、样式美化、hover 效果 |

---

## 任务依赖关系

```
[任务1] 分析现有设计变量（颜色、字体、spacing）
        ↓
[任务2] 重新设计字段行信息层级（TSX 结构改造）
        ↓
[任务3] 调整布局 grid 结构
        ↓
[任务4] 样式美化（温暖优雅色调）
        ↓
[任务5] 添加 hover 展开技术细节交互
        ↓
[任务6] 主键标识增强（加粗 + 暖色标识）
        ↓
[任务7] 响应式适配（桌面端）
        ↓
[任务8] 动效微调（保持流畅）
```

---

## 详细任务分解

### 任务1：分析现有设计变量
- [ ] 查看项目中 CSS 变量定义（`var(--bg-elevated)`, `var(--primary)` 等）
- [ ] 确定可复用的颜色 token
- [ ] 确认字体系统（等宽字体/无衬线字体）

### 任务2：重新设计字段行信息层级（TSX）

**默认展示（L1）**：
- 字段名（加粗）+ 主键标识（增强样式）
- 规范化类型中文标签（如"字符串""数字"）

**Hover 展示（L2 技术细节）**：
- 原始数据类型（`rawDataType`）
- 可空标识（`nullable`）
- 规范化类型英文标识

### 任务3：调整布局 grid 结构

原结构：
```scss
grid-template-columns: 1.5fr auto auto;  // 字段名 | 原始类型 | (规范化+可空)
```

新结构：
```scss
grid-template-columns: 1fr auto;  // 字段名+主键 | 规范化类型标签
```

hover 时展开 rawDataType 和 nullableTag

### 任务4：样式美化（温暖优雅色调）

- [ ] 规范化类型标签：从灰色改为暖色系（如琥珀色、暖棕色背景）
- [ ] 主键标识：从钥匙图标改为左侧暖色竖线 + 字段名加粗
- [ ] 整体间距调整：增加行高至 40-44px，提升呼吸感
- [ ] 表头背景色：更温暖的色调

### 任务5：Hover 展开交互

- [ ] 技术细节（rawDataType + nullableTag）默认 `opacity: 0; max-height: 0`
- [ ] hover 时 `opacity: 1; max-height: 48px; transition`
- [ ] 使用 `max-height` 而非 `height` 动画

### 任务6：主键标识增强

- [ ] 保留钥匙图标但缩小
- [ ] 添加左侧 2-3px 暖色竖线
- [ ] 字段名 `font-weight: 600`

### 任务7：响应式适配（桌面端优先）

- [ ] 保持桌面端布局稳定
- [ ] 考虑极端长字段名的截断策略

### 任务8：动效微调

- [ ] 入场动画保持 `fadeIn`
- [ ] hover 过渡 `0.2s ease`
- [ ] 确保 `prefers-reduced-motion` 兼容

## 预期效果预览

**默认状态**（业务人员视角）：
```
┌─────────────────────────────────────────────┐
│ 📋 users                                    │
├─────────────────────────────────────────────┤
│ ┃ username     ▐ 字符串                      │
│ ┃ id           ▐ 数字                        │
│   created_at   ▐ 日期                       │
│   email         ▐ 字符串                     │
└─────────────────────────────────────────────┘
```

**Hover 状态**（技术人员视角）：
```
┌─────────────────────────────────────────────┐
│ 📋 users                                    │
├─────────────────────────────────────────────┤
│ ┃ username     ▐ 字符串                      │
│               │ varchar(255)  nullable      │
│ ┃ id           ▐ 数字                        │
│               │ int  PK                      │
│   created_at   ▐ 日期                      │
│               │ timestamp                   │
└─────────────────────────────────────────────┘
```

## 实现顺序

1. **先改 TSX 结构**（任务2）
2. **再改 SCSS 布局**（任务3）
3. **最后加样式和动效**（任务4-8）

## 验证标准

- [ ] 业务人员：默认只看到字段名和中文类型，清晰易懂
- [ ] 技术人员：hover 能快速看到原始类型和可空标识
- [ ] 整体风格：温暖优雅，无冷色/刺眼配色
- [ ] 性能：动画流畅，无布局抖动
