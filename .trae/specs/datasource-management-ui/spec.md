# 数据源管理界面 Spec

## Why

用户需要一个完整的数据源管理界面，能够创建、查看、删除数据源，并查看数据源的详细信息（表结构、列信息、外键关系）。当前系统已有后端 API 支持，但缺少前端界面。

## What Changes

新增数据源管理模块，包含以下功能：
- 数据源列表页面（路由：/datasource）
- 创建数据源弹窗（支持 MySQL、PostgreSQL、ClickHouse）
- 数据源详情页面（显示表结构、列信息、外键关系）
- 删除数据源功能（带二次确认，检查是否被使用）
- 空状态设计
- 响应式设计（桌面端、平板端、移动端）

## Impact

- 新增模块：`apps/web-client/src/modules/datasource/`
- 依赖模块：`#pkg/seedar/ui-react`（使用 useDatasources, useCreateDatasource, useDeleteDatasource）
- 前端影响：新增路由 /datasource 和 /datasource/:id
- 设计规范：使用项目现有的暖棕主题色系和 CSS 变量

## ADDED Requirements

### Requirement: 数据源列表页面
系统 SHALL 提供数据源列表页面，展示所有数据源的基本信息

#### Scenario: 查看数据源列表
- **WHEN** 用户访问 /datasource 路由
- **THEN** 显示数据源列表页面，包含：
  - 页面标题："数据源管理"
  - "创建数据源"按钮
  - 数据源列表（卡片形式）
  - 每个数据源卡片显示：名称、类型、连接信息、创建时间、状态
  - 操作按钮：查看详情、删除

#### Scenario: 空状态显示
- **WHEN** 数据源列表为空
- **THEN** 显示友好的空状态，包含：
  - 空状态图标
  - 提示文字："暂无数据源"
  - 引导文字："点击'创建数据源'开始使用"

### Requirement: 创建数据源弹窗
系统 SHALL 提供创建数据源的弹窗界面

#### Scenario: 选择数据源类型
- **WHEN** 用户打开创建数据源弹窗
- **THEN** 显示三种数据源类型卡片：
  - MySQL（关系型数据库）
  - PostgreSQL（关系型数据库）
  - ClickHouse（列式数据库）
- 用户点击卡片选择数据源类型

#### Scenario: 配置连接信息
- **WHEN** 用户选择数据源类型后
- **THEN** 显示连接配置表单：
  - 数据源名称（必填）
  - 主机地址（必填）
  - 端口号（必填，根据类型自动填充默认值）
  - 数据库名称（必填）
  - 用户名（必填）
  - 密码（必填，支持显示/隐藏切换）
  - 实时验证输入格式

#### Scenario: 测试连接
- **WHEN** 用户点击"测试连接"按钮
- **THEN** 系统调用后端 API 测试连接：
  - 显示加载状态（⏳ 正在测试连接...）
  - 连接成功显示：✅ 连接成功！用时 X.Xs
  - 连接失败显示：❌ 连接失败：[错误信息]

#### Scenario: 创建数据源
- **WHEN** 用户填写完表单并点击"创建数据源"按钮
- **THEN** 系统调用创建 API：
  - 显示提交中状态
  - 创建成功后关闭弹窗
  - 显示成功提示（使用 sonner toast）
  - 刷新数据源列表

### Requirement: 数据源详情页面
系统 SHALL 提供数据源详情页面，展示数据源的完整信息

#### Scenario: 查看数据源详情
- **WHEN** 用户点击数据源卡片的"查看详情"按钮
- **THEN** 跳转到 /datasource/:id 页面，显示：
  - 数据源基本信息（名称、类型、连接信息、状态）
  - 表结构列表
  - 每个表的列信息
  - 外键关系列表

#### Scenario: 查看表结构
- **WHEN** 用户在详情页面查看表结构
- **THEN** 每个表显示：
  - 表名
  - 表注释（如果有）
  - 列信息（列名、数据类型、是否可空、是否主键）
  - 外键关系

### Requirement: 删除数据源
系统 SHALL 提供删除数据源功能，包含二次确认和使用检查

#### Scenario: 删除数据源（未使用）
- **WHEN** 用户点击"删除"按钮，数据源未被任何数据集使用
- **THEN** 显示确认弹窗：
  - 提示："确定要删除数据源 [数据源名称] 吗？"
  - 确认后调用删除 API
  - 删除成功后刷新列表
  - 显示成功提示

#### Scenario: 删除数据源（已被使用）
- **WHEN** 用户点击"删除"按钮，数据源已被数据集使用
- **THEN** 显示错误提示：
  - 提示："该数据源正在被使用，无法删除"
  - 列出使用该数据源的数据集名称
  - 不允许删除

## 设计规范

### 颜色使用
- 主色：`--primary` (#a0522d) - 主要按钮、重要链接
- 成功色：`--success` (#6b8e4e) - 连接成功、删除成功
- 危险色：`--danger` (#b85450) - 删除按钮、错误提示
- 文字色：`--text-primary` (#5a4a3a) - 主要文字
- 背景色：`--bg-elevated` (#ffffff) - 卡片、弹窗背景
- 边框色：`--border-base` (#d5c4b0) - 输入框、卡片边框

### 间距规范
- 卡片间距：`--spacing-lg` (16px)
- 表单字段间距：`--spacing-md` (12px)
- 按钮间距：`--spacing-md` (12px)
- 弹窗内边距：`--spacing-xl` (24px)

### 圆角规范
- 卡片圆角：`--radius-lg` (8px)
- 输入框圆角：`--radius-base` (6px)
- 按钮圆角：`--radius-base` (6px)

### 字体规范
- 页面标题：`--font-xl` (16px), font-weight: 600
- 卡片标题：`--font-lg` (14px), font-weight: 500
- 正文：`--font-base` (13px)
- 辅助文字：`--font-sm` (12px)

### 过渡动画
- 悬停效果：`--transition-fast` (0.1s ease)
- 弹窗动画：`--transition-base` (0.15s ease)

### 响应式断点
- 桌面端：> 1200px
- 平板端：768px - 1200px
- 移动端：< 768px

## 可访问性

- 所有交互元素支持键盘导航（Tab 键）
- 表单字段有清晰的标签和错误提示
- 按钮有明确的焦点指示器
- 色彩对比度符合 WCAG AA 标准
- 使用语义化 HTML 结构
- 添加 ARIA 标签
