# React+TS组件hooks层规范
## 核心职责
定义hooks目录下自定义Hook的职责、书写、命名、逻辑约束
## 边界范围
仅覆盖hooks目录及下属Hook文件，不涉及其他目录
## 强制规范
### 使用规范
- 核心职责：存放当前组件专属的自定义Hook，封装业务逻辑、数据获取、事件处理、状态联动；**禁止在Hook中存储状态**，状态统一存入store
- 单一职责：每个Hook专注于单一逻辑，禁止一个Hook封装多个无关逻辑
- 作用域：Hook仅供当前组件及子组件使用，不对外暴露；无私有逻辑时可删除该文件夹，禁止为空文件夹

### 书写规范
- 导入顺序（固定）：1. 外部依赖（React hooks、第三方工具）；2. 内部资源（store、types、utils）
- Hook结构：默认导出Hook函数，函数名与文件名一致，内部按「定义依赖→编写逻辑→返回结果」排序
- 异步逻辑：接口请求、定时器等异步操作，需在useEffect中执行，必须完善清理函数（清除定时器、取消请求），避免内存泄漏
- 返回值：返回对象（便于解构），仅暴露视图层需要的数据和方法，禁止返回store实例、原始接口数据
- 注释：Hook函数、关键逻辑、返回值需加注释，说明用途、参数、返回值含义

### 禁止行为
- 禁止在Hook中操作视图、修改Props
- 禁止使用any类型
- 禁止重复封装相同逻辑的Hook
- 禁止在Hook中存储组件状态（状态必须存入store）
