# React+TS组件utils层规范
## 核心职责
定义utils目录下工具函数的职责、书写、命名、约束
## 边界范围
仅覆盖utils目录及工具函数，不涉及其他目录
## 强制规范
### 使用规范
- 核心职责：存放当前组件专属的纯工具函数，用于数据格式化、过滤、计算、类型转换；无状态、无副作用、不依赖组件上下文
- 纯函数约束：所有工具函数必须是纯函数，输入相同则输出必相同，禁止依赖外部状态
- 作用域：工具函数仅供当前组件及子组件使用，不对外暴露；无工具函数时可删除该文件夹，禁止为空文件夹

### 书写规范
- 导入约束：仅导入外部工具、类型定义，禁止导入store、hooks、context等内部资源
- 参数与返回值：所有参数、返回值必须标注类型，禁止any类型；可选参数设置默认值
- 注释：每个工具函数需加注释，说明功能、参数、返回值含义，复杂逻辑加内部注释
- 文件组织：按功能分类组织函数，同类型函数放在一起，拆分文件时每个文件仅存放一类功能

### 禁止行为
- 禁止在工具函数中写业务逻辑、操作store、发起接口请求
- 禁止使用全局变量
- 禁止编写重复的工具函数
- 禁止工具函数依赖组件内部上下文资源
