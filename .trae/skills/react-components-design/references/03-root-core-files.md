# React+TS组件根目录核心文件规范
## 核心职责
定义根目录下index.ts、组件主文件（tsx）、样式文件（module.css/scss/less）、types.ts的使用、书写、内容、导入导出规范
## 边界范围
仅覆盖「组件根目录直接下属的4个核心文件」，不涉及子目录（components/pages等）内的文件
## 强制规范
### 1. index.ts（唯一对外出口）
#### 使用规范
仅用于对外导出组件、组件Props类型，不写任何业务逻辑、实现代码；禁止导出store、context、hooks、utils等内部私有资源。
#### 书写规范
- 固定模板，仅2行导出语句，无多余代码：
```typescript
// 导出组件（默认导出）
export { default } from './组件名';
// 导出组件Props类型（按需导出）
export type { 组件名Props } from './types';
```
- 导入使用相对路径，禁止绝对路径；先导出组件，后导出Props类型，不可颠倒
- 禁止内容：禁止写实现、调试代码，禁止导出内部资源

### 2. 组件主文件（xxx.tsx，视图编排层）
#### 使用规范
核心职责是视图编排，仅做组件/子组件组装、UI渲染，无复杂业务逻辑、无数据请求、无状态修改（仅消费状态）；禁止写hooks逻辑、store操作、接口请求。
#### 书写规范
- 导入顺序（固定）：1. 外部依赖（React、第三方组件）；2. 样式文件；3. 内部资源（hooks、store、子组件等），同类型按字母排序
- 组件结构：先解构Props、获取状态，再编写JSX，无多余嵌套
- JSX规范：单个标签独占一行，缩进2空格；属性按「核心属性→事件属性→其他属性」排序；禁止行内样式
- Props处理：必须解构Props，可选Props设置默认值，禁止直接使用`props.xxx`
- 禁止内容：禁止写业务逻辑、接口请求，禁止any类型，禁止JSX中写复杂计算

### 3. 样式文件（xxx.module.xxx，样式隔离层）
#### 使用规范
采用CSS Modules实现样式隔离，仅服务当前组件，禁止污染全局；禁止引入外部全局样式。
#### 书写规范
- 样式层级：嵌套不超过3层，按「根容器→子元素→状态类」排序
- 约束：禁止使用`!important`，禁止全局选择器（*、body等）
- 预处理器规范（SCSS/LESS）：
  - 变量统一放在顶部，按「全局→组件专属」分类，禁止重复定义
  - 混合宏仅用于当前组件，命名语义化，可接收参数
  - 合理使用嵌套，禁止过度嵌套；仅允许导入全局变量文件，禁止导入其他组件样式
  - 禁止使用条件判断、循环等复杂语法

### 4. types.ts（类型收敛层）
#### 使用规范
收敛当前组件所有类型定义，包括Props、状态、回调、context、子组件类型等；禁止在其他文件重复定义类型，禁止any、隐式类型。
#### 书写规范
- 书写顺序（固定）：1. 事件回调类型；2. 组件Props类型；3. store状态类型；4. context类型；5. 子组件类型
- 类型定义：优先用interface定义对象类型，type定义联合/交叉类型；禁止any，未知类型用unknown+类型守卫
- 状态类型：结构扁平化，禁止多层嵌套；默认避免null，用undefined替代
- 注释：每个类型、关键属性加简单注释，说明用途
- 禁止内容：禁止重复定义，禁止定义无关类型，禁止隐式类型
