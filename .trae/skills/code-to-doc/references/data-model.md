# 数据模型文档生成规范

## 文档目标

帮助新人快速掌握系统数据结构，理解核心实体及其关系，无需了解数据库表结构和代码类定义。

## 支持的数据存储方式

- 关系型数据库（PostgreSQL、MySQL、SQL Server、Oracle）
- 文档型数据库（MongoDB、CouchDB）
- 键值存储（Redis、Memcached）
- 图数据库（Neo4j、ArangoDB）
- 搜索引擎（Elasticsearch、Solr）

## 文档结构

1. 核心实体概览
2. 实体详细说明（每个实体包含：基本信息、关键字段、实体关系）
3. 实体关系图（Mermaid ER图）
4. 数据流转（Mermaid流程图）

## 通用生成步骤

1. 识别数据存储方式
2. 查找实体定义（根据ORM和编程语言）
3. 提取实体信息（名称、功能、字段）
4. 提取字段类型映射（将编程语言类型映射为通用类型）
5. 提取实体关系（一对一、一对多、多对多）
6. 提取字段说明（从注释、字段名、验证规则等）
7. 生成实体关系图
8. 生成数据流转图
9. 生成文档

## 注意事项

- 字段类型应使用业务友好的名称（如"string"而非"VARCHAR(255)"）
- 示例值应真实可用
- 关系说明应清晰易懂
- ER图应包含所有核心实体
- 避免使用数据库专业术语
- 适用于不同数据存储方式
- 适用于不同编程语言和ORM
- 字段说明应简洁明了
