# 代码变更与文档更新映射规则

## 文档定位

明确**代码变更类型、代码粒度、文档类型**三者的精准映射关系，指导 Subagent 自动判定「哪些文档需要更新、更新哪部分、如何更新」，避免漏更/错更。

## 适用范围

所有通过`code-to-doc`技能执行的文档更新操作，覆盖代码片段/单文件/模块/项目所有粒度，适配所有支持的编程语言和项目类型。

## 核心定义

1. **代码变更类型**：功能新增、功能修改、功能删除、异常逻辑调整、配置/环境调整；
2. **代码粒度**：代码片段、单文件代码、模块代码、项目代码；
3. **文档类型**：API 文档、快速入门指南、核心业务逻辑文档、数据模型文档、FAQ 文档、PRD 文档。

## 核心映射规则（三维匹配）

### 通用前置规则

- 仅**模块/项目级**代码变更触发 PRD 文档更新，片段/单文件变更不涉及 PRD；
- 所有代码变更若涉及**异常逻辑/使用问题**，均需同步更新 FAQ 文档；
- 配置/环境调整仅触发**快速入门指南**更新，不涉及其他文档类型。

### 详细映射表

| 代码变更类型              | 代码粒度  | 需更新的文档类型                     | 核心更新内容                            |
| ------------------------- | --------- | ------------------------------------ | --------------------------------------- |
| 功能新增（接口）          | 所有粒度  | API 文档、FAQ 文档                   | API 新增接口描述，FAQ 补充使用问题      |
| 功能新增（数据实体）      | 所有粒度  | 数据模型文档、FAQ 文档               | 数据模型新增实体/关系，FAQ 补充使用问题 |
| 功能新增（业务流程）      | 模块/项目 | 核心业务逻辑文档、PRD 文档（项目级） | 补充流程节点，PRD 更新边界/目标         |
| 功能修改（接口参数/逻辑） | 所有粒度  | API 文档、FAQ 文档                   | 修改接口描述，FAQ 更新异常场景          |
| 功能修改（数据实体/字段） | 所有粒度  | 数据模型文档、FAQ 文档               | 修改实体/字段描述，FAQ 更新关联问题     |
| 功能修改（业务流程/规则） | 模块/项目 | 核心业务逻辑文档、PRD 文档（项目级） | 修改流程/规则，PRD 按需更新             |
| 功能删除（接口）          | 所有粒度  | API 文档、FAQ 文档                   | 接口标注废弃，FAQ 说明替代方案          |
| 功能删除（数据实体）      | 所有粒度  | 数据模型文档、FAQ 文档               | 实体标注废弃，FAQ 说明替代方案          |
| 功能删除（业务流程）      | 模块/项目 | 核心业务逻辑文档、PRD 文档（项目级） | 流程标注废弃，PRD 更新边界              |
| 异常逻辑调整              | 所有粒度  | FAQ 文档、核心业务逻辑文档（按需）   | FAQ 更新异常处理，流程按需补充          |
| 配置/环境调整             | 所有粒度  | 快速入门指南                         | 同步更新环境配置/启动步骤               |

## 代码粒度差异化更新深度规则

1. **代码片段**：仅更新片段对应的**核心逻辑描述/FAQ**，不涉及其他文档，更新内容 ≤50 字；
2. **单文件代码**：仅更新文件对应的**单接口/单实体/单功能描述+关联 FAQ**，不跨文件更新，更新内容 ≤100 字；
3. **模块代码**：按映射表更新模块内所有对应文档，聚焦**模块内内容**，不涉及跨模块交互；
4. **项目代码**：按映射表更新项目级所有对应文档，弱化单模块细节，强化**跨模块交互/全局规则**的更新。

## 代码特征识别规则（无语言依赖）

Subagent 通过**功能特征**识别代码变更类型，不依赖固定语言/框架/命名，核心识别点：

1. **接口变更**：识别 HTTP 路由/GraphQL 节点/函数入口的新增/修改/注释删除；
2. **数据实体变更**：识别实体类/模型类的字段新增/修改/注释删除；
3. **业务流程变更**：识别流程判断节点/调用链路的新增/修改；
4. **异常逻辑调整**：识别 try/catch/异常抛出语句的修改/新增；
5. **配置/环境调整**：识别配置文件/环境变量/启动参数的修改/新增。

## 特殊变更处理规则

1. **全局规则变更**（如接口限流、全局权限）：仅触发**项目级 API 总览/PRD**更新，模块级 API 文档标注全局规则链接；
2. **跨模块交互变更**：仅触发**项目级核心业务逻辑/数据模型总览**更新，模块级文档标注跨模块关联说明；
3. **兼容式变更**（如接口新增可选参数，不影响原有使用）：更新文档时标注「**向下兼容**」，无需修改原有使用示例；
4. **非兼容式变更**（如接口删除必选参数，影响原有使用）：更新文档时标注「**非向下兼容，需同步调整调用方**」，并补充适配示例。
