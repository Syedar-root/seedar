# 常见问题解答（FAQ）生成规范

## 文档目标

减少新人初期困惑，提升信心，提供高频问题的直接解决方案。

## 支持的项目类型

- Web 应用、API 服务、CLI 工具、库/SDK、桌面应用、移动应用

## 文档结构

1. 快速问题索引（按类别分组）
2. 问题详细解答（每个问题包含：问题、答案、示例、相关链接）

## 常见问题类别

### 通用类别

- 安装配置、环境问题、依赖问题、启动问题、使用问题

### Web 应用/API 服务

- API 调用、认证授权、数据操作、错误处理、性能问题

### CLI 工具

- 命令使用、参数配置、输出解析、错误处理

### 库/SDK

- 安装导入、API 使用、错误处理、类型定义、版本兼容

## 通用生成步骤

1. 识别项目类型
2. 查找常见问题来源（README.md、docs/faq.md、CONTRIBUTING.md、TROUBLESHOOTING.md 等）
3. 识别问题类别
4. 提取高频问题（从 Issues、文档、测试代码等）
5. 提取解决方案（从错误处理代码、验证代码、文档等）
6. 组织问题和答案
7. 生成文档

## 注意事项

- 问题应简洁明了
- 答案应直接可操作
- 示例应完整可运行
- 分类应清晰合理
- 避免使用技术术语
- 提供相关链接（如适用）
- 适用于不同项目类型
- 适用于不同编程语言
- 定期更新问题和答案
