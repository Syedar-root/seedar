### 模块一：数据源接入与元数据管理模块

#### **核心功能**

1. 配置数据源（MySQL / CSV / Excel）

2. 测试并校验数据源连接

3. 查询数据源基础配置

4. 拉取并查询数据源表结构与字段元数据

5. 刷新数据源元数据

6. 修改数据源配置

7. 移除数据源（逻辑删除）

### 模块二：轻量语义建模模块

#### 核心功能

1. 创建数据集：基于已配置的数据源，定义一个可分析的数据集对象。

2. 选择数据集类型：支持语义模型与宽表模型两种数据集构建方式。

3. 选择基础表结构：从数据源中选择参与建模的基础表。

4. 配置表关系：定义表间 Join 路径，在查询时根据预先配置的关系生成合法的 Join 结构。

5. 配置宽表结构：定义宽表字段映射关系，并描述数据同步策略（如 T+1）。

6. 管理字段语义：为字段配置业务语义、类型与角色，并声明可用的聚合能力。

7. 定义自定义指标：支持用户自定义带语义的计算字段，表达式可包含行级、聚合级及后聚合计算。

8. 查询数据集元信息：获取数据集结构、可用字段、可用指标及可用计算能力。

9. 修改数据集配置：支持对数据集结构与语义配置进行调整，不保证历史结果一致性。

10. 删除或禁用数据集：移除数据集分析能力，不影响底层数据源与原始数据。

### 模块三：可视化查询构建模块

#### 核心功能

1. 创建查询定义

2. 更新查询定义

3. 删除查询定义

4. 查询查询定义列表 / 详情

#### 实体设计

```typescript
/**
 * 查询状态
 */
export enum QueryStatus {
  DRAFT = "draft",
  PUBLISHED = "published",
  DISABLED = "disabled",
}

/**
 * 查询定义实体
 * 对应表：query_definition
 *
 * 模块三的一等公民
 * 表示一次“分析意图”的结构化描述
 */
export interface QueryDefinitionEntity {
  /** 主键 */
  id: number;

  /** 绑定的语义数据集（模块二） */
  dataSetId: number;

  /** 查询名称（业务可读） */
  name: string;

  /** 查询描述 */
  description?: string;

  /** 查询 DSL（核心） */
  dsl: QueryDSL;

  /** 查询状态 */
  status: QueryStatus;

  /** 创建人 */
  createdBy: number;

  /** 创建时间 */
  createdAt: Date;

  /** 更新时间 */
  updatedAt: Date;
}

/* =========================
 * Query DSL（值对象，不单独建表）
 * ========================= */

/**
 * 查询 DSL
 * 对语义查询意图的结构化表达
 */
export interface QueryDSL {
  /** 查询上下文（冗余一份，保证 DSL 自描述） */
  dataSetId: number;

  /** 查询选择项 */
  select: {
    dimensions: DimensionRef[];
    metrics: MetricRef[];
  };

  /** 过滤条件（语义级） */
  filters?: FilterExpr[];

  /** 排序规则 */
  orderBy?: OrderExpr[];

  /** 行数限制 */
  limit?: number;
  offset?: number;
}

/* =========================
 * DSL 子结构（全部语义引用）
 * ========================= */

/**
 * 维度引用
 * 对应模块二：DataSetField
 */
export interface DimensionRef {
  /** dataset_field.id */
  fieldId: number;

  /** 时间粒度（仅时间维度可用） */
  granularity?: "day" | "week" | "month" | "year";

  /** 别名 */
  alias?: string;
}

/**
 * 指标引用
 * 对应模块二：
 * - DataSetField（字段型指标）
 * - DataSetMetric（自定义指标）
 */
export interface MetricRef {
  /** dataset_field.id（字段型指标） */
  fieldId?: number;

  /** dataset_metric.id（自定义指标） */
  metricId?: number;

  /** 聚合方式（仅字段型指标需要） */
  aggregation?: "sum" | "count" | "avg" | "max" | "min";

  /** 指标别名 */
  alias?: string;
}

/**
 * 过滤表达式
 * 对应模块二：DataSetField
 */
export interface FilterExpr {
  /** dataset_field.id */
  fieldId: number;

  operator: "=" | "!=" | ">" | ">=" | "<" | "<=" | "in" | "between";

  value: any;
}

/**
 * 排序表达式
 * 基于 select 结果排序
 */
export interface OrderExpr {
  /** dimension alias 或 metric alias */
  by: string;
  direction: "asc" | "desc";
}

/* =========================
 * 可选扩展实体（非必须）
 * ========================= */

/**
 * 查询版本（轻量级，论文加分）
 * 对应表：query_version
 */
export interface QueryVersionEntity {
  /** 主键 */
  id: number;

  /** 关联查询定义 */
  queryId: number;

  /** 当时的 DSL 快照 */
  dsl: QueryDSL;

  /** 创建时间 */
  createdAt: Date;
}

/**
 * 查询默认展示偏好（非图表实例）
 * 对应表：query_chart_preference
 */
export interface QueryChartPreferenceEntity {
  /** 查询 ID */
  queryId: number;

  /** 推荐图表类型 */
  chartType: "table" | "bar" | "line" | "pie";

  /** 创建时间 */
  createdAt: Date;
}
```

#### 数据库设计

```sql
CREATE TABLE query_definition (
  id VARCHAR(36) PRIMARY KEY,
  dataset_id VARCHAR(36) NOT NULL,

  name VARCHAR(100) NOT NULL,
  description TEXT,

  dsl JSON NOT NULL,

  status VARCHAR(20) DEFAULT 'draft',

  created_by VARCHAR(36),
  created_at TIMESTAMP,
  updated_at TIMESTAMP,

  INDEX idx_dataset_id (dataset_id)
);

```

### 模块四：查询执行与结果处理模块

#### 核心功能

1. 校验查询 DSL

2. 解析查询 DSL

3. 执行查询（Adapter 转换并执行）

4. 查询结果归一化

5. 查询异常处理

#### Adapter 设计

```typescript
/**
 * 查询执行结果（统一返回结构）
 */
export interface QueryExecuteResult {
  fields: Array<{
    name: string;
    type: "string" | "number" | "date";
  }>;
  rows: any[];
}

/**
 * 查询执行 Adapter 基类
 * 模块四的设计核心
 */
export abstract class BaseAdapter {
  /**
   * 执行查询
   * @param dsl 已校验的 QueryDSL
   */
  abstract execute(dsl: QueryDSL): Promise<QueryExecuteResult>;
}
```
