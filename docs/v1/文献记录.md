## 国内研究现状

1. 李康年. 面向商务智能语义层的可视化查询软件的设计与实现[D]. 北京:北京大学,2009.
2. 杨梦琴. 语义驱动的数据查询与智能可视化研究[D]. 重庆:重庆大学,2018.

国内在数据查询语义化、可视化分析领域的研究起步较早，且伴随商务智能（BI）、自助式数据分析技术的发展逐步深化，形成了学术理论探索与工程化产品落地双线并行的发展格局，研究重心从早期面向传统商务智能的语义层查询实现，逐步向轻量化、语义驱动、自然语言交互与嵌入式可视化方向演进。
在早期研究阶段，国内学者聚焦商务智能语义层的可视化查询软件设计，解决传统 BI 系统中业务人员查询门槛高、语义复用性差的问题。李康年 [1] 针对传统商务智能应用的语义层查询缺陷，设计并实现了面向商务智能语义层的可视化查询软件，通过细粒度划分语义查询组件、完全面向对象的语义对象建模，实现了语义查询到 SQL 的自底向上转换，同时支持外部数据分析功能扩展与多 BI 系统语义层适配。该研究首次将语义层抽象与可视化查询结合，解决了业务人员无需编写 SQL 即可完成数据查询的核心需求，奠定了国内 BI 领域语义查询的技术基础。但受限于当时的技术架构，该研究仅适配传统商务智能系统，采用本地部署模式，存在架构偏重、语义模型配置复杂、不支持轻量化私有化部署等问题，无法适配中小团队的灵活使用场景。
随着自然语言处理与深度学习技术的发展，国内研究转向语义驱动的自然语言查询与智能可视化方向，重点突破自然语言转 SQL（NL2SQL）与图表智能推荐的技术瓶颈。杨梦琴 [2] 针对关系型数据库自然语言查询难、可视化适配性差的问题，提出语义驱动的数据查询与智能可视化模型，基于 LSTM 神经网络与 Word2Vec 词嵌入技术构建 NL2SQL 模型，通过 SQL 依赖关系图解决了传统 Seq2Seq 模型的查询条件顺序问题，同时结合表格透镜与表代数实现高维数据的智能可视化推荐，将自然语言查询的 SQL 生成准确率提升 15%。该研究实现了自然语言交互与可视化的深度融合，大幅降低了数据查询的操作门槛。但该研究偏向学术实验，仅支持单表查询与简单 SQL 生成，未考虑企业级场景的语义口径统一、跨表关联建模需求，且未形成可私有化部署、可嵌入式复用的工程化方案，难以直接落地于企业实际业务系统。
在工程化产品与应用层面，国内已涌现出多款成熟的数据分析与可视化工具，形成了覆盖企业级与中小团队的产品体系，但在轻量化与语义建模结合层面仍存在明显短板。面向大型企业的产品侧重语义治理与全功能覆盖，语义建模能力完善，但架构厚重、私有化部署与定制化成本高；面向中小团队的开源产品上手门槛低、功能轻量化，但语义层建模能力薄弱，缺乏统一的指标口径管理与跨表关联设计，同时嵌入式集成能力不足，无法与企业现有业务系统深度融合。整体来看，国内现有产品尚未形成兼顾轻量语义建模、可视化查询、嵌入式复用与私有化部署的一体化解决方案，与中小团队低成本、灵活化、可嵌入的数据分析需求存在 mismatch。
综上，国内相关研究与产品已完成从传统 BI 语义查询到自然语言驱动可视化查询的技术迭代，早期研究奠定了语义层与可视化结合的理论基础，中期研究突破了自然语言转 SQL 与智能可视化的技术瓶颈，现有产品则覆盖了不同规模企业的基础数据分析需求。但现有研究仍存在明显缺口：早期研究技术架构老旧、轻量化不足，中期学术研究缺乏工程化落地能力，现有产品则在轻量语义建模、嵌入式能力与私有化部署的平衡上存在短板。针对这一缺口，开展轻量语义建模的可视化查询系统研究，整合轻量化语义抽象、拖拽式可视化查询、AI 辅助自然语言交互与嵌入式可视化能力，既贴合国内企业数字化的实际需求，也填补了当前研究与产品的技术空白，具备重要的研究价值与实践意义。

## 国外研究现状

[9] SUBHA R. Dedicated Semantic Layer Architecture for Effective Data Analytics and Visualization: A Case Study[J]. International Journal of Innovative Science and Research Technology, 2024, 9(10): 612-618. https://doi.org/10.38124/ijisrt/IJISRT24OCT1676  
[10] RODRIGUES P d N, SILVA A R d. Controlled Natural Languages for Specifying Business Intelligence Applications[EB/OL]. 2023-11-21. https://doi.org/10.48550/arXiv.2311.11895.
[11] AODENG G, LI G, FENG Y, et al. InReAcTable: LLM-Powered Interactive Visual Data Story Construction from Tabular Data[EB/OL]. (2025-08-25)[2025-12-18]. https://doi.org/10.48550/arXiv.2508.18174

国外在商业智能（BI）、语义建模与可视化查询领域的研究起步较早，已形成理论规范、技术方法、系统实现三位一体的研究体系，围绕受控自然语言、大模型驱动交互、专用语义层架构三大方向持续演进，为轻量语义建模与可视化查询系统的研发奠定了坚实基础。
在 BI 应用的语义规范与形式化描述方向，国外学者率先聚焦自然语言歧义性问题，提出受控自然语言（CNL）用于精准定义 BI 系统需求与数据语义。Rodrigues 等 [2] 针对传统自然语言需求描述模糊、难以机器解析的痛点，设计了 CNL-BI 与 ITLingo ASL 两类受控自然语言，构建了覆盖多维数据模型、OLAP 操作、交互式图表的语言规范，实现了医疗 BI 场景中维度、事实、用例与 UI 组件的形式化描述。该研究明确了语义建模的核心要素 —— 将物理数据映射为业务可理解的逻辑视图，通过约束词汇与语法消除歧义，为轻量语义层的字段抽象、关联定义提供了标准化范式。同期，国外学界围绕数据仓库与 OLAP 技术的语义建模展开大量研究，确立了星型模型、雪花模型的语义组织原则，推动语义层从 “数据映射” 向 “业务语义封装” 升级，成为后续可视化查询系统的底层理论支撑。
在大模型驱动的交互式可视化分析方向，近年来以大语言模型（LLM）为核心的智能交互技术成为研究热点，彻底革新了传统可视化查询的人机交互模式。Aodeng 等 [1] 提出的 InReAcTable 框架，针对表格数据可视化故事构建中洞察碎片化、用户认知负担重的问题，创新性融合结构过滤与语义推理双模块：通过子空间图缩小数据搜索范围，结合检索增强生成（RAG）与思维链（CoT）prompt，实现与用户分析意图对齐的动态洞察推荐，支撑迭代式可视化数据故事构建。该研究突破了传统可视化查询 “固定规则” 的局限，将 LLM 的语义理解能力与数据可视化的探索性分析结合，验证了 “轻量语义抽象 + 智能交互” 在降低用户使用门槛、提升分析效率上的核心价值。此外，国外大量研究围绕自然语言转可视化（NL2VIS）展开，VizGPT、LIDA 等工具实现了自然语言查询到可视化图表的自动生成，进一步完善了可视化查询的智能交互链路。
在语义层架构与商业化系统落地层面，国外已完成从 “工具内嵌语义” 到 “专用语义层（DSL）” 的演进，形成成熟的技术产品体系。早期国外 BI 产品（如 Tableau、Power BI）将语义层封装在工具内部，虽提升了单工具使用体验，但形成数据语义孤岛；后续 Looker 推出 LookML、Uber 构建 uMetric 专用语义层，实现了跨平台、可复用的业务指标与数据语义统一管理，完全契合专用语义层 “解耦物理数据与业务视图” 的核心优势。当前国外主流可视化查询产品（如 Metabase、QuickSight）均已集成轻量语义建模能力，支持业务人员无代码定义维度、指标与表关联，拖拽式完成可视化查询配置，同时开放嵌入式 SDK 满足业务系统集成需求，实现了学术研究与工业落地的深度融合。这类产品既保留了语义建模的轻量化特性，又兼顾了可视化查询的易用性，成为中小团队数据分析的主流选择。
尽管国外研究与产品已形成成熟体系，但仍存在针对性短板：一是传统语义建模方案依赖专业建模人员，轻量化程度不足，难以适配中小团队快速部署需求；二是大模型驱动的可视化分析多聚焦数据洞察与故事生成，针对私有化部署、嵌入式集成的企业级场景适配不足；三是商业化产品虽功能完善，但在自定义语义口径、可控化 SQL 生成等层面灵活性欠缺。
综上，国外在受控自然语言语义规范、大模型交互式可视化、专用语义层架构三大领域的研究成果，为本课题轻量语义建模、可视化查询引擎、AI 辅助交互的设计提供了直接理论参考与技术借鉴；而现有研究在轻量化、私有化、嵌入式场景的不足，也明确了本课题的研究切入点与创新方向。
