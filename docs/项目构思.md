## 项目构思（最终规范版）

本项目面向企业内部的自助分析场景，旨在构建一套 **轻量化、可私有化部署、基于 DSL 的可视化查询系统**，覆盖从数据接入、语义抽象、可视化查询到图表呈现的完整分析链路。系统主要面向两类用户：  
（1）**技术人员**：习惯使用结构化数据库（MySQL）  
（2）**业务人员（产运）**：更依赖 CSV / Excel 作为数据来源  

因此，本项目明确 **仅支持 MySQL 与 CSV/Excel 两类数据源**，既贴合企业实际，也确保系统复杂度和开发范围可控。

在架构设计上，系统采用统一的 **查询 DSL（JSON Schema）** 来描述用户的分析意图，通过拖拽式交互生成 DSL，而非依赖手写 SQL。后端基于 **Adapter 模式** 将 DSL 分别转换为对应的数据源执行逻辑：  
- **MySQL Adapter**：将 DSL 转换为参数化、模板化的 SQL  
- **CSV/Excel Adapter**：将 DSL 转换为 DataFrame 的过滤、聚合和排序操作  

这种方式确保了系统具备“一套模型，多种数据源”的通用性，同时避免引入 SQL AST、SQL 解析器、多方言兼容等高复杂度能力，使项目保持轻量、可实现。

系统提供一个 **轻量语义层**，用于对数据源的字段、维度和指标进行基础抽象，使业务人员能够在统一语义下理解数据结构。语义层仅包含字段别名、字段类型、基本聚合定义和简单的单层表关系，不涉及复杂的数据血缘、多跳 join 推断或指标体系治理，从而保持工程可控性与可交付性。

在查询构建层面，系统提供 **拖拽式可视化查询界面**，用户可将维度、指标、筛选条件等操作通过拖拽完成，前端自动生成 DSL Schema。系统对 Schema 进行基础合法性校验，通过适配器执行后返回统一格式的数据供前端可视化展示。

在可视化呈现层面，系统支持折线图、柱状图、饼图、表格等常见可视化类型，并通过图表配置 Schema 和看板布局管理，实现简单的可视化拼装能力。该模块保持轻量，不涉及复杂图层、交互分析、权限分享等重型能力。

此外，项目引入 **轻量级 AI 辅助功能**，包括自然语言描述转 DSL Schema、图表类型推荐和自动生成可视化草稿等，以降低业务人员的使用门槛。AI 模块作为辅助角色，不负责 SQL 生成，也不参与复杂数据分析，以确保系统整体的确定性与可控性。

综合而言，本项目的核心价值在于：  
- 提供 **统一、轻量的查询建模方式（DSL）**  
- 简化 MySQL 与 CSV/Excel 的数据访问体验  
- 让业务人员通过拖拽即可完成查询  
- 以适配器实现跨数据源的执行一致性  
- 保持系统技术深度适配 “毕业设计可实现范围”  

最终，本项目将形成一套可私有化部署、工程边界清晰、核心链路完整的可视化查询原型系统，可满足企业日常的数据查看、基础分析与可视化看板构建需求。
