# 模块文档索引

本目录是 `docs/v2/dev-docs/` 的第二层文档体系，用于把项目级总览继续拆成“面向开发与维护”的模块级设计文档。

如果说第一层总文档的重点是：

- 项目解决什么问题
- 整体架构如何设计
- 哪些内容适合写入论文

那么第二层模块文档的重点就是：

- 某个模块到底负责什么
- 前端、后端、共享包在这个模块中如何配合
- 日常开发和后续维护应该优先看哪些文件
- 哪些地方最容易踩坑

## 1. 适合谁阅读

本目录特别适合以下几类读者：

1. 需要接手某个具体模块的开发者
2. 需要按模块拆分论文“详细设计”章节的写作者
3. 需要快速定位问题边界的维护者

## 2. 模块目录说明

| 目录 | 核心问题 | 典型读者 |
| --- | --- | --- |
| [datasource](./datasource/README.md) | 如何把外部数据库接入并缓存元数据 | 后端、数据接入相关开发者 |
| [dataset](./dataset/README.md) | 如何把物理表结构整理成语义数据集 | 数据建模、产品逻辑开发者 |
| [query](./query/README.md) | 如何把 DSL 转成 SQL 并执行 | 查询引擎、后端核心开发者 |
| [dashboard](./dashboard/README.md) | 如何把查询结果变成面板与仪表盘资产 | 前端可视化、交互开发者 |
| [ai](./ai/README.md) | AI 如何调用工具、感知页面并触发 workflow | AI、全栈、体验设计开发者 |
| [cli](./cli/README.md) | 系统如何安装、升级、诊断和运行 | 运维、交付、平台工程相关开发者 |
| [shared-packages](./shared-packages/README.md) | 共享类型、前端基础层与指标引擎如何分工 | 需要改共享层或做跨模块重构的开发者 |

## 3. 推荐阅读策略

### 3.1 按“问题”阅读

如果你当前关心的是某个问题，可以直接定位到对应模块：

- “为什么数据源详情里会有表和外键信息？”  
  先读 `datasource`
- “为什么数据集创建时会校验主键和 Join？”  
  先读 `dataset`
- “为什么面板能在前端运行却不需要手写 SQL？”  
  先读 `query`
- “为什么仪表盘只保存布局和关系，不复制面板？”  
  先读 `dashboard`
- “为什么 AI 不只是聊天，还会操作页面？”  
  先读 `ai`
- “为什么系统推荐通过 CLI 安装而不是脚本部署？”  
  先读 `cli`

### 3.2 按“开发任务”阅读

如果你已经知道自己要改什么，可以按以下方式进入：

1. 先读项目级 [seedar-frontend-backend-map.md](../seedar-frontend-backend-map.md)，找到问题落在哪条链路。
2. 再进入本目录对应模块，阅读 `README + overview`。
3. 如果需要继续深挖，再读该模块下的流程、映射和维护文档。

### 3.3 按“论文章节”阅读

如果你要写毕业论文的“详细设计”，模块级文档很适合转化成：

- 数据源模块设计
- 数据集模块设计
- 查询模块设计
- AI 模块设计
- 仪表盘模块设计

## 4. 如何理解本目录与项目级总文档的关系

二者不是替代关系，而是上下层关系：

### 第一层总文档回答

- 这个系统整体是什么
- 为什么这样设计
- 技术路线与架构是什么

### 第二层模块文档回答

- 某个模块具体怎么工作
- 改这个模块时先看哪里
- 这个模块和别的模块如何衔接

## 5. 当前目录的使用建议

如果你时间有限，我建议每个模块至少先读这两份：

- `README.md`
- `overview.md`

如果你要真正动代码，再继续读：

- 流程类文档，如 `business-flow.md`、`execution-flow.md`、`panel-flow.md`
- 映射类文档，如 `frontend-backend-map.md`
- 运维或风险类文档，如 `maintenance.md`

## 6. 后续可继续增强的方向

本目录后续还可以继续向第三层演化，例如：

- `dataset` 进一步拆成字段、Join、指标三个专题文档
- `query` 补充 DSL 例子字典和字段映射规则
- `dashboard` 补充面板配置 schema 与展示组件映射
- `ai` 补充前端 interrupt 协议与工具调用时序说明

目前这一层已经足够支撑：

- 模块级开发接手
- 详细设计说明
- 论文中模块章节的初稿撰写
