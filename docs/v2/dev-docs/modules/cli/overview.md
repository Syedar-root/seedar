# CLI 模块概览

## 1. 模块职责

CLI 负责：

- 安装运行时
- 启停服务
- 升级版本
- 查看状态与日志
- 诊断问题
- 卸载与清理

它并不是“顺手写的脚本集合”，而是系统工程化能力的重要组成部分。

## 2. 设计动机

如果没有 CLI，Seedar 的部署将面临以下问题：

1. 用户必须理解仓库结构。
2. 用户必须手动维护 `.env`、compose 文件和版本信息。
3. 升级和回滚难以标准化。
4. 运维体验依赖脚本和口口相传知识。

CLI 的设计就是为了解决这些问题。

## 3. 推荐使用方式

生产环境推荐入口是：

```bash
npx @syedar/seedar-cli@latest install
```

而不是直接在仓库里运行老的 PowerShell 脚本。

## 4. 核心命令族

当前 CLI 的核心命令族包括：

- `install`
- `start`
- `stop`
- `update`
- `status`
- `logs`
- `doctor`
- `uninstall`
- `remove`
- `purge`

这说明它已经覆盖了安装生命周期的大部分阶段。

## 5. 为什么它重要

它把部署细节从“开发仓库知识”变成“用户可执行命令”，这对交付和运维很关键。

## 6. 论文可用描述

“CLI 模块是系统工程化的重要组成部分。它通过统一管理安装、升级、状态查询、日志查看和运行时目录结构，使系统的部署过程标准化、可复制化，从而提升了平台的可交付性与可维护性。”
