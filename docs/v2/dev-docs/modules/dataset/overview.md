# 数据集模块概览

## 1. 模块职责

数据集模块的职责是把数据源层的物理结构提升成可分析的语义结构。

它负责：

- 选表
- 定义字段
- 管理主键
- 管理 Join
- 管理指标

## 2. 模块边界

它向上承接：

- 数据源元数据

它向下输出：

- Query 可执行所需的数据语义结构

## 3. 关键约束

1. 数据集必须挂在一个数据源下面。
2. 字段不能为空。
3. 含主键的源表，其主键必须进入数据集。
4. 多表建模必须能推导出 Join。

## 4. 核心子对象

- `Dataset`
- `DatasetTable`
- `DatasetField`
- `DatasetJoin`
- `DatasetMetric`
