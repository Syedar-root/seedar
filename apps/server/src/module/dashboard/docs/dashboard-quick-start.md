# Dashboard 模块快速入门指南

## 1. 简介

Dashboard 模块是一个用于创建和管理仪表盘的功能模块，支持添加不同类型的面板（如图表、表格、文本和卡片），并可以自定义仪表盘布局。

本指南将帮助你快速上手使用 Dashboard 模块，包括环境准备、基本操作和常见用例。

## 2. 环境准备

### 2.1 前提条件

- Node.js 14.0 或更高版本
- NestJS 框架
- TypeORM
- 数据库（支持 PostgreSQL、MySQL、SQLite 等）

### 2.2 模块安装

Dashboard 模块已集成在项目中，无需单独安装。确保项目已正确配置：

1. 确保数据库连接配置正确
2. 运行数据库迁移：
   ```bash
   npm run migration:run
   ```

## 3. 基本操作

### 3.1 创建仪表盘

**步骤 1**：发送 POST 请求到 `/dashboard` 接口

**请求示例**：
```bash
curl -X POST http://localhost:3000/dashboard \
  -H "Content-Type: application/json" \
  -d '{"name": "销售仪表盘", "layout": {"panels": []}}'
```

**响应示例**：
```json
{
  "id": "123e4567-e89b-12d3-a456-426614174000",
  "name": "销售仪表盘",
  "layout": {"panels": []},
  "createdAt": "2024-01-01T00:00:00.000Z",
  "updatedAt": "2024-01-01T00:00:00.000Z"
}
```

### 3.2 创建面板

**步骤 1**：发送 POST 请求到 `/panel` 接口

**请求示例**：
```bash
curl -X POST http://localhost:3000/panel \
  -H "Content-Type: application/json" \
  -d '{"title": "销售趋势", "type": "chart", "width": 6, "height": 4}'
```

**响应示例**：
```json
{
  "id": "987e6543-210b-4567-8901-234567890123",
  "title": "销售趋势",
  "type": "chart",
  "width": 6,
  "height": 4,
  "createdAt": "2024-01-01T00:00:00.000Z",
  "updatedAt": "2024-01-01T00:00:00.000Z"
}
```

### 3.3 向仪表盘添加面板

**步骤 1**：发送 POST 请求到 `/dashboard/:id/panels` 接口

**请求示例**：
```bash
curl -X POST http://localhost:3000/dashboard/123e4567-e89b-12d3-a456-426614174000/panels \
  -H "Content-Type: application/json" \
  -d '{"panelId": "987e6543-210b-4567-8901-234567890123"}'
```

### 3.4 更新仪表盘布局

**步骤 1**：发送 PUT 请求到 `/dashboard/:id/layout` 接口

**请求示例**：
```bash
curl -X PUT http://localhost:3000/dashboard/123e4567-e89b-12d3-a456-426614174000/layout \
  -H "Content-Type: application/json" \
  -d '{
    "panels": [
      {
        "id": "987e6543-210b-4567-8901-234567890123",
        "row": 1,
        "col": 1,
        "width": 6,
        "height": 4
      }
    ]
  }'
```

## 4. 常见用例

### 4.1 创建包含多种面板的仪表盘

**场景**：创建一个销售分析仪表盘，包含销售趋势图、销售数据表格和关键指标卡片。

**步骤**：
1. 创建仪表盘
2. 创建销售趋势图面板（类型：chart）
3. 创建销售数据表格面板（类型：table）
4. 创建关键指标卡片面板（类型：card）
5. 将所有面板添加到仪表盘中
6. 更新仪表盘布局

### 4.2 关联查询数据

**场景**：创建一个显示数据库查询结果的面板。

**步骤**：
1. 先创建一个查询（使用 Query 模块）
2. 创建面板时指定 `queryId` 关联该查询
3. 面板将自动显示查询结果

### 4.3 自定义面板配置

**场景**：为图表面板设置自定义配置，如颜色、图例等。

**步骤**：
1. 创建面板时在 `config` 字段中设置自定义配置
2. 或通过 PATCH 请求更新面板配置

**示例配置**：
```json
{
  "config": {
    "colors": ["#1f77b4", "#ff7f0e", "#2ca02c"],
    "legend": true,
    "xAxis": {"label": "日期"},
    "yAxis": {"label": "销售额"}
  }
}
```

## 5. 面板类型说明

| 类型 | 描述 | 适用场景 |
|------|------|----------|
| `chart` | 图表面板，用于展示趋势和对比数据 | 销售趋势、用户增长等 |
| `table` | 表格面板，用于展示详细数据列表 | 销售明细、用户列表等 |
| `text` | 文本面板，用于展示说明文字或静态内容 | 仪表盘说明、业务规则等 |
| `card` | 卡片面板，用于展示单个关键指标 | 总销售额、用户数等 |

## 6. 故障排除

### 6.1 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 面板不显示数据 | 未关联查询或查询无结果 | 检查 `queryId` 是否正确，确保查询有数据 |
| 布局更新失败 | 布局格式不正确 | 确保布局 JSON 格式正确，包含必要的字段 |
| 面板添加失败 | 面板不存在 | 检查面板 ID 是否正确 |

### 6.2 错误码

| 状态码 | 含义 | 解决方法 |
|--------|------|----------|
| 404 | 资源不存在 | 检查请求的 ID 是否正确 |
| 400 | 请求参数错误 | 检查请求体格式是否正确 |
| 500 | 服务器内部错误 | 查看服务器日志，排查错误原因 |
