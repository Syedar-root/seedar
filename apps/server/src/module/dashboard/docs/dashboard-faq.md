# Dashboard 模块常见问题解答

## 1. 基础问题

### 1.1 什么是 Dashboard 模块？

Dashboard 模块是一个用于创建、管理和展示仪表盘的功能模块，支持添加不同类型的面板（如图表、表格、文本和卡片），并可以自定义仪表盘布局。布局支持响应式设计，适配不同屏幕尺寸。

### 1.2 Dashboard 模块支持哪些面板类型？

Dashboard 模块支持四种面板类型：
- **chart**：图表面板，用于展示趋势和对比数据
- **table**：表格面板，用于展示详细数据列表
- **text**：文本面板，用于展示说明文字或静态内容
- **card**：卡片面板，用于展示单个关键指标

### 1.3 如何创建一个仪表盘？

可以通过发送 POST 请求到 `/dashboard` 接口创建仪表盘，请求体中包含仪表盘名称和可选的布局配置。

**示例请求**：
```json
{
  "name": "销售仪表盘"
}
```

## 2. 面板相关问题

### 2.1 如何创建一个面板？

可以通过发送 POST 请求到 `/panel` 接口创建面板，请求体中包含面板标题、类型、查询 ID、配置、宽高等信息。

**示例请求**：
```json
{
  "title": "销售趋势",
  "type": "chart",
  "queryId": "uuid",
  "config": {},
  "width": 6,
  "height": 4
}
```

### 2.2 如何将面板添加到仪表盘中？

可以通过发送 POST 请求到 `/dashboard/:id/panels` 接口，将面板添加到仪表盘中。

**示例请求**：
```json
{
  "panelId": "uuid"
}
```

### 2.3 面板类型有什么区别？

| 类型 | 描述 | 适用场景 |
|------|------|----------|
| `chart` | 图表面板，用于展示趋势和对比数据 | 销售趋势、用户增长等 |
| `table` | 表格面板，用于展示详细数据列表 | 销售明细、用户列表等 |
| `text` | 文本面板，用于展示说明文字或静态内容 | 仪表盘说明、业务规则等 |
| `card` | 卡片面板，用于展示单个关键指标 | 总销售额、用户数等 |

## 3. 布局相关问题

### 3.1 如何更新仪表盘布局？

可以通过发送 PUT 请求到 `/dashboard/:id/layout` 接口，更新仪表盘布局。

**示例请求**：
```json
{
  "lg": [
    {
      "i": "panel-uuid",
      "x": 0,
      "y": 0,
      "w": 6,
      "h": 4
    }
  ],
  "md": [
    {
      "i": "panel-uuid",
      "x": 0,
      "y": 0,
      "w": 4,
      "h": 4
    }
  ]
}
```

### 3.2 布局配置有什么格式要求？

布局配置是一个 JSON 对象，支持五个响应式断点：

| 断点 | 描述 | 典型屏幕宽度 |
|------|------|-------------|
| `lg` | 大屏幕 | ≥1200px |
| `md` | 中等屏幕 | ≥996px |
| `sm` | 小屏幕 | ≥768px |
| `xs` | 超小屏幕 | ≥480px |
| `xxs` | 极小屏幕 | <480px |

每个布局项包含以下字段：

| 字段 | 类型 | 必填 | 描述 |
|------|------|------|------|
| `i` | string | 是 | 面板 ID（对应 panel.id） |
| `x` | number | 是 | 水平位置（网格列号） |
| `y` | number | 是 | 垂直位置（网格行号） |
| `w` | number | 是 | 宽度（网格列数） |
| `h` | number | 是 | 高度（网格行数） |
| `minW` | number | 否 | 最小宽度 |
| `minH` | number | 否 | 最小高度 |
| `maxW` | number | 否 | 最大宽度 |
| `maxH` | number | 否 | 最大高度 |
| `static` | boolean | 否 | 是否静态 |
| `isDraggable` | boolean | 否 | 是否可拖拽 |
| `isResizable` | boolean | 否 | 是否可调整大小 |

### 3.3 如何设计一个合理的仪表盘布局？

- 按照信息重要性排列面板
- 相关面板放在一起
- 避免面板重叠
- 合理使用空间，避免浪费
- 为不同屏幕尺寸配置不同的布局
- 考虑响应式布局，适应不同屏幕尺寸

### 3.4 布局中的面板 ID 有什么要求？

布局中的面板 ID（`i` 字段）必须对应已存在的面板。系统会在创建或更新布局时验证面板 ID 的有效性，如果包含无效的面板 ID，将返回 400 错误。

## 4. 数据相关问题

### 4.1 面板如何关联查询数据？

在创建面板时，可以通过 `queryId` 字段关联一个查询。面板将自动显示查询结果。

### 4.2 如何自定义面板配置？

在创建或更新面板时，可以通过 `config` 字段设置自定义配置。配置格式根据面板类型不同而不同。

**示例配置**：
```json
{
  "config": {
    "colors": ["#1f77b4", "#ff7f0e", "#2ca02c"],
    "legend": true,
    "xAxis": {"label": "日期"},
    "yAxis": {"label": "销售额"}
  }
}
```

### 4.3 面板数据加载慢怎么办？

- 检查查询性能
- 考虑添加数据缓存
- 优化面板配置
- 减少面板数量
- 分页加载大量数据

## 5. 错误处理问题

### 5.1 收到 404 错误怎么办？

404 错误通常表示请求的资源不存在。请检查：
- 仪表盘 ID 是否正确
- 面板 ID 是否正确
- 面板是否在仪表盘中

### 5.2 收到 400 错误怎么办？

400 错误通常表示请求参数错误。请检查：
- 请求体格式是否正确
- 必填参数是否提供
- 参数值是否有效
- **布局中的面板 ID 是否存在**

### 5.3 收到 500 错误怎么办？

500 错误通常表示服务器内部错误。请：
- 查看服务器日志
- 检查数据库连接
- 检查代码是否有 bug
- 联系开发人员
