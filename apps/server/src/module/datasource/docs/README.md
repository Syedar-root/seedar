## 模块概述

数据源模块是系统的基础组件，负责管理各种类型的数据源连接、元数据获取和数据处理。该模块支持多种数据源类型，包括 MySQL、PostgreSQL、ClickHouse、CSV 和 Excel。

## 核心功能

1. **数据源管理**：创建、查询、更新和删除数据源
2. **配置管理**：验证、加密和更新数据源配置
3. **连接管理**：测试、创建和维护数据源连接
4. **元数据管理**：自动获取和管理数据源的元数据
5. **安全管理**：确保数据源操作的安全性

## 技术栈

- **框架**：NestJS
- **ORM**：TypeORM
- **数据库查询**：Knex
- **配置管理**：@nestjs/config
- **加密**：自定义加密实现

## 支持的数据源类型

- MySQL
- PostgreSQL
- ClickHouse
- CSV
- Excel

## 注意事项

- 配置中的敏感信息（如密码）会被加密存储
- 创建和更新数据源时会自动测试连接
- 数据源创建成功后会自动获取表结构和外键关系
- 删除操作采用软删除方式，保留操作记录
- 元数据获取失败不影响数据源的基本功能

## 维护说明

- 定期检查数据源状态，确保连接正常
- 监控连接池使用情况，及时调整配置
- 记录数据源操作日志，便于审计和追溯
- 定期更新数据库驱动和依赖库，确保兼容性
